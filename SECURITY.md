# Security Policy

## Supported Versions

The following versions of `nti-crewai-template` are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

We take the security of Neutral Trust Infrastructure (NTI) multi-agent systems seriously. If you discover a vulnerability or potential security issue, please follow these guidelines:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email your security findings to `security@neutraltrust.io` or report directly to the repository maintainers.
3. Include detailed steps to reproduce the issue, along with any relevant proof-of-concept code or logs.

### Response Expectations

- **Initial Response:** Within 48 hours of report submission.
- **Triage & Status Update:** Within 5 business days.
- **Fix Disclosure:** We coordinate patch releases and advisory publication with reporters before public release.

Thank you for helping keep NTI multi-agent workflows secure!
